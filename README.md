# 🎮 Hangman Game

A simple Hangman word guessing game created using Python.

## 📌 About the Project

In this game, the player has to guess the hidden word by entering one letter at a time.

The player gets a maximum of 6 incorrect guesses. The game ends when the player guesses the word correctly or reaches 6 incorrect guesses.

## 🛠️ Technologies Used

- Python

## ✨ Features

- Random word selection
- Letter-by-letter guessing
- Tracks already guessed letters
- Shows correct and wrong guesses
- Maximum 6 incorrect guesses
- Displays the correct word when the game is over

## ▶️ How to Run

Open the terminal in VS Code and run:

```bash
python hangman.py
```

## 🎯 How to Play

1. Run the program.
2. Enter one letter when asked.
3. If the letter is correct, it appears in the word.
4. If the letter is wrong, the incorrect guess count increases.
5. Try to guess the complete word before reaching 6 incorrect guesses.
